# IntentProbe Qwen2.5-0.5B activation probe

**Author:** [Wan Sheng Leung](https://github.com/ithiria894) · **Publisher:** MCPware

[Architecture: one local model pass, many task-specific probes](https://mcpware.github.io/IntentProbe/architecture/)
· [All IntentProbe models and research](https://github.com/mcpware/IntentProbe)

This repository contains the 22 KB linear probe used by
[IntentProbe](https://github.com/mcpware/IntentProbe), a local research-preview scanner for MCP tool
descriptions and agent skills. It scores mean-pooled hidden states from a frozen
[Qwen2.5-0.5B](https://huggingface.co/Qwen/Qwen2.5-0.5B) sensor.

**This is not a standalone text classifier.** The probe needs IntentProbe and Qwen2.5-0.5B to produce
its 2,688 activation features. Do not load `probe_weights.npz` with a Transformers text-classification
pipeline, and do not interpret the 22 KB probe size as the runtime footprint. The first local scan
downloads the approximately 1 GB base model.

## Quick start

The PyPI package already includes this probe:

```bash
python3 -m pip install intentprobe
intentprobe scan --format summary \
  --text "Reads SSH config and private keys, then silently uploads credentials to a remote server."
```

To pin the probe files from this Hub repository:

```bash
python3 -m pip install intentprobe huggingface_hub
hf download mcpware/intentprobe-qwen2.5-0.5b \
  --local-dir ./intentprobe-qwen2.5-0.5b
intentprobe scan \
  --artifact ./intentprobe-qwen2.5-0.5b \
  --format summary \
  --text "A calculator that adds two numbers."
```

After the base-model download, inference stays local. The CLI does not upload scan text or results.

## What the artifact does

| Component | Release value |
| --- | --- |
| Base sensor | `Qwen/Qwen2.5-0.5B` |
| Features | Attention-mask-aware mean pooling of hidden-state indices 13, 14, and 15 |
| Maximum input | 256 tokens; longer input is truncated |
| Probe | Binary logistic regression |
| Feature dimension | 2,688 |
| Probe file | `probe_weights.npz`, 22,286 bytes |
| Warn threshold | 0.30 |
| Block threshold | 0.85 plus static corroboration under `corroborated-block-v4` |
| Runtime role | Local review signal before install or use |

The probe is the primary activation signal for `allow` and `warn`. IntentProbe's hard `block` decision
also requires corroborating static evidence. A high activation score without that corroboration is a
warning for review, not an automatic hard block.

## Release benchmark

The release benchmark froze this artifact, its layers, and its thresholds before scoring the pinned
[`yoonholee/agent-skill-malware`](https://huggingface.co/datasets/yoonholee/agent-skill-malware)
corpus at revision `5cff435ddab2cc34261875885de9ac50d40393ec`. The pinned file contains 347 rows,
not the 350 stated in its card. Two benign rows exactly matched normalized training text and were
excluded, leaving 345 rows: 124 malicious and 221 benign.

| Frozen score | AUROC | 95% cluster-bootstrap CI | Average precision |
| --- | ---: | ---: | ---: |
| Activation probe | **0.935** | **0.907–0.961** | **0.904** |
| TF-IDF logistic regression, same 989 training rows | 0.626 | 0.563–0.685 | 0.447 |
| IntentProbe static score | 0.611 | 0.563–0.657 | 0.469 |
| Current max(activation, static) risk score | 0.902 | 0.869–0.932 | 0.796 |
| Dataset-authored campaign signature | 1.000 | 1.000–1.000 | 1.000 |

The paired activation-minus-TF-IDF AUROC difference is **+0.309**, with a 95% cluster-bootstrap CI of
**+0.249 to +0.374** (2,000 resamples, seed 42). The dataset-authored signature is intentionally
fitted to the known campaign indicators in this same corpus. Its perfect score demonstrates why
precise signatures should remain in the stack; it is not an out-of-distribution baseline.

At the shipped policy thresholds, `warn` or `block` finds 116/124 malicious rows (recall 0.935,
Clopper-Pearson 95% CI 0.877–0.972) and warns or blocks 74/221 benign rows (FPR 0.335, 95% CI
0.273–0.401). The corroborated hard-block tier finds 11/124 malicious rows (recall 0.089, 95% CI
0.045–0.153) with 0/221 clean blocks (FPR 0; 95% upper bound 0.0166). This operating point is useful as
a review signal, not as a standalone automatic security boundary.

The machine-readable receipt, including row scores, excluded IDs, hashes, exact intervals, and runtime
settings, is generated by
[`research/benchmark_hf_blind_agent_skills.py`](https://github.com/mcpware/IntentProbe/blob/main/research/benchmark_hf_blind_agent_skills.py)
and stored as
[`hf_blind_agent_skill_malware.json`](https://github.com/mcpware/IntentProbe/blob/main/research/_results_published/hf_blind_agent_skill_malware.json).

These release numbers are separate from the fit diagnostic in `metadata.json`. The training-set F1 in
that file measures whether the probe fitted its 989 training rows; it is not a generalization result
and should not be cited as model performance.

Broader results, including the shipped fixed configuration on four prompt-injection sources and
leave-one-corpus-out tool-poisoning comparisons, are documented in the
[IntentProbe README](https://github.com/mcpware/IntentProbe#benchmarks). The headline evidence is
deliberately qualified: prompt-injection cross-source performance is stronger than current
tool-poisoning evidence, and a text classifier remains competitive or better on some
within-distribution matched-vocabulary tests.

## Training data and reproducibility

The probe was fitted on 989 English rows: 423 clean and 566 poisoned. The pool combines MCPTox rows,
curated matched pairs, hard negatives, and synthetic or adapted carriers across eight risk families.
An overlap audit found 965 unique normalized texts. The repository does not upload the mixed-source
training dataset as a Hugging Face dataset because its row-level provenance and license review is not
yet complete.

The original artifact metadata records the base-model identifier but not the immutable Qwen revision
used during training. Release benchmarking resolves Qwen `main` to
`060db6499f32faf8b98477b0a26969ef7d8b9987`. A future weight revision should retrain from a pinned
base-model commit rather than retroactively claiming that the current training run was pinned.

Artifact integrity:

| File | SHA-256 |
| --- | --- |
| `probe_weights.npz` | `ffd777469dc0376d651f59ea1e2d7ec44d988e68c6d506d45e7957b643b0e409` |
| `metadata.json` | `e7e6b3ff3ea8f47800aacf56c19b11db275af95d572732e16d6ba0c587c1810c` |

The weight file contains only numeric NumPy arrays (`coef`, `intercept`, and `classes`), not pickle.
IntentProbe loads it with `allow_pickle=False` and validates required keys, shapes, class order,
feature dimension, and finite values.

## Intended use

- Review MCP tool descriptions, skill files, and similar capability text before installation.
- Add a complementary activation signal beside static rules and other scanners.
- Reproduce or extend activation-probe research on a small frozen sensor model.

## Limitations

- Research preview: this is a review signal, not a security boundary.
- English-only training and evaluation; multilingual behavior is not established.
- One sensor family: the weights do not transfer to another base model or Qwen size.
- Inputs are truncated at 256 tokens. Content after that boundary is invisible to this artifact.
- Training data mixes public, curated, synthetic, adapted, and weak-label sources. It does not
  establish real-world prevalence or product-grade coverage.
- The current tool-poisoning evidence is partial. Some cross-source results are positive; other
  minimal-pair and within-distribution tests are ties or losses against TF-IDF.
- Thresholds were previously inspected on the RouteGuard-related corpus. Results on that corpus are
  calibration audits, not untouched prospective estimates.
- Known campaign indicators should remain in static signatures. An activation probe complements,
  rather than replaces, precise signatures for known threats.
- The scanner evaluates inert text. It does not execute a skill or prove what an agent will do.

## Privacy and the demo

The installed CLI runs inference locally after downloading the base model. A future public Space is a
different environment: use only synthetic examples there, and do not paste credentials, private
prompts, proprietary MCP configurations, or confidential skill files. For private material, install
and run IntentProbe locally.
